# ResumeIQ 🚀

ResumeIQ is an AI-powered resume analysis platform that helps job seekers optimize their resumes for Applicant Tracking Systems (ATS) and improve their chances of getting hired.

## ✨ Features

- 🔐 Secure User Authentication (Login / Signup)
- 📄 Resume Upload (PDF)
- 📝 Job Description Analysis
- 🎯 ATS Score Evaluation
- 📊 Job Match Percentage
- ✅ Matched Skills Detection
- ⚠️ Missing Skills Identification
- 💡 AI-Powered Suggestions
- 💪 Resume Strengths Analysis
- 🔍 Resume Weakness Analysis
- 📥 Downloadable Analysis Report
- ⚡ Modern Responsive UI
- 🔔 Toast Notifications
- ⏳ Skeleton Loading States
